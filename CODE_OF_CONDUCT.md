# Code of conduct

StremioNow adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and take constructive feedback, and keep discussions about the project. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer, [@AffonsoPaulo](https://github.com/AffonsoPaulo), using the contact on their GitHub profile. Reports are handled confidentially.

## Scope

This code applies to every project space and to anyone representing the project in public.
